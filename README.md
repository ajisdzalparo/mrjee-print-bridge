# Mrjee Print Bridge

Produk komersial untuk customer umum.

- Lisensi subscription dan aktivasi perangkat.
- Endpoint produksi dilindungi lisensi dan bearer token.
- Demo trial lokal tetap menggunakan payload test terbatas.
- Repository, App ID, data aplikasi, shortcut, dan installer terpisah dari Internal Edition.

Internal Edition tidak boleh dijadikan dependency atau submodule repository ini.
