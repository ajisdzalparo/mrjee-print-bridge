# Mrjee Print Bridge v1.0.0 — Free Edition

Rilis publik pertama untuk silent printing dari aplikasi web ke printer Windows.

## Highlights

- Gratis dan tidak membutuhkan license key
- Unlimited local print jobs
- PDF, RAW, ZPL, SBPL, ESC/POS, dan image
- Logical printer mapping
- Bearer token dan CORS security
- System tray dan auto-start
- Notifikasi update manual yang tidak mengganggu printing
- Offline-first

## Asset

`Mrjee Print Bridge Setup 1.0.0.exe`

## Verifikasi

Unduh installer hanya dari release resmi. Windows dapat menampilkan SmartScreen
karena binary belum memiliki code-signing certificate; periksa publisher dan
checksum release sebelum menjalankan.
